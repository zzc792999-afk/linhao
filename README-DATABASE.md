# 25计算机1 · Render 免费部署版

版本 4.0。网站部署在原 Render Free Web Service，业务数据存到原 Neon PostgreSQL，不需要付费磁盘。render.yaml 和 render-database.yaml 均为免费 Node 服务配置；render-preview.yaml 保留静态展示配置。

[开始 Render 部署](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Fzzc792999-afk%2Flinhao)

## 1. 创建 Neon 免费数据库

1. 打开 https://console.neon.tech ，可以使用 GitHub 注册或登录。
2. 保持 Free 免费计划，创建项目，例如 class-2501；选择靠近 Render 服务的区域。
3. 点击 Connect，复制 PostgreSQL 连接字符串（以 postgresql:// 开头）。保留原有的 sslmode=require 等参数，可以使用 pooled connection。
4. 连接字符串包含密码，只填写在 Render 的 DATABASE_URL 环境变量中。不要上传到 GitHub，不要放入 public，也不需要在聊天中发送。

本项目启动时会自动建表，无需手动运行 SQL。当前未配置远程数据库时，不能宣称网站已上线或留言已同步。

## 2. 在 Render 免费部署

1. 关闭此前要求绑卡的付费配置页面，打开上面的“开始 Render 部署”链接，读取最新 main 分支配置。
2. 在 Blueprint 的 Blueprint Path 字段填写 render-database.yaml，然后确认服务 Plan 为 Free，并且没有 Persistent Disk、付费数据库或其他付费资源。
3. 在 DATABASE_URL 输入框中粘贴 Neon 连接字符串，再确认创建。
4. 等待状态变为 Live，使用 Render 提供的 https://…onrender.com 地址访问。
5. 用电脑发一条留言，手机打开同一网址检查。再做一次 Restart，确认留言仍保留。

如果 Blueprint 页面仍要求付款，可取消，然后从 Render 的 New → Web Service 手动选择本仓库并按以下参数创建。免费资源有额度限制；若 Render 仍要求账户验证，需按实际账户要求处理，不要切换到付费计划。

手动创建参数：
- Runtime: Node
- Branch: main
- Root Directory: 留空
- Build Command: npm ci --omit=dev
- Start Command: npm start
- Instance Type: Free
- Health Check Path: /healthz
- 环境变量 NODE_ENV=production
- 环境变量 DATABASE_URL=从 Neon 复制的完整连接字符串
- 不添加磁盘，不创建 Render 数据库
- PORT 由 Render 提供，代码自动读取

## 免费额度与保存规则

按当前官方说明，Neon Free 无固定试用到期时间且无需信用卡，但有数据库容量、计算、流量等额度限制。Render 免费服务空闲 15 分钟后会休眠，下一次访问约需一分钟唤醒，每个工作区每月共享 750 免费实例小时。你已有的其他免费服务也可能消耗这个额度。

Render 的免费 PostgreSQL 会在 30 天后到期，因此这套配置使用 Neon。免费方案不保证永远可用或无上限，请保持免费计划并关注额度和服务通知。

- Render 重启、休眠和重新部署不会删除外部 Neon 数据库中的留言。
- 保持使用同一个 DATABASE_URL；删除 Neon 项目或数据库会删除数据。
- 定期通过数据库工具执行 pg_dump 做独立备份，免费计划的备份能力以提供方规则为准。

官方参考：
- https://render.com/docs/free
- https://neon.com/pricing
- https://neon.com/docs/get-started/connect-neon

## 本地预览

安装 Node.js 24，在文件夹运行 npm ci（只需首次或依赖变化时），再运行 npm start，访问 http://localhost:3000。
也可以双击“启动网站.bat”。本地未设置 DATABASE_URL 时，自动使用 data/class.db，便于离线预览；这份本地数据不会自动迁移到 Neon。

如需本地连接 Neon，可在终端通过环境变量设置 DATABASE_URL，不要把密码写进代码。线上 Render 缺少 DATABASE_URL 会直接拒绝启动，防止误用临时磁盘丢失留言。

## 功能与范围

- 全班共享留言和点赞；活跃页面每 30 秒同步，页面隐藏或空闲超过 2 分钟后暂停，操作后恢复。
- 显示最新 200 条留言，旧留言仍保存在数据库。
- 昵称限 16 字，留言限 200 字，同一浏览器每次发布需间隔至少 10 秒。
- 通过 HttpOnly Cookie 区分浏览器，只能删除当前浏览器发布的留言。清除 Cookie 或换设备会失去原留言的删除权限。
- 点赞按浏览器计算，没有实名账号；管理员通过独立后台管理内容，详见后面的后台说明。
- 照片保存到同一 Neon 数据库的 photos 表（BYTEA），所有设备共享；JPG、PNG、WebP 原图不超过 15MB，浏览器及服务器自动压缩为最长边 1600px 的 JPEG，移除照片元数据。服务端接收不超过 8MB、解码不超过 4000 万像素、成品不超过 1MB。相册最多 200 张且总计不超过 100MB；满额拒绝新上传，不会覆盖旧照片。只有当前浏览器能删除自己上传的照片，清除 Cookie 后会失去删除权限。静态展示页不能上传。
- 原始照片位于 public/assets，更新文件后重新部署。

## 班级游乐场与管理员后台

- 正式站首页增加班级投票、每日心情签到、随机点名、幸运签和班级公告。投票按浏览器记一票，可在结束前改选；签到按北京时间每天记一份，可修改当天心情。它们不是实名身份或正式选举系统。
- `/admin` 是管理后台，使用独立密码。可管理全部留言与上传照片、发布和结束投票、设置公告与点名名单、查看统计和管理记录、修改管理员密码。留言管理每页 50 条，支持翻页。
- 管理员密码使用随机盐及 scrypt 派生，不保留明文。初始化时将编码后的 `ADMIN_PASSWORD_HASH` 配置为服务器环境变量。后续在后台修改密码会将新哈希保存在现有数据库，优先于初始化环境变量。
- 登录会话使用 HttpOnly、SameSite=Strict Cookie，生产环境启用 Secure。服务端只保存会话令牌哈希，会话有效期 8 小时，退出后撤销当前会话，修改密码后所有旧会话失效。管理接口继续执行来源校验，并限制登录尝试。
- 初始化管理员登录资料已交付到本机独立文件，不在仓库或 public 中；不要分享密码文件。忘记密码时，维护者可在数据库中安全重置 admin_password_hash，并同时更新初始化环境变量，旧登录自动失效。
- 新增 class_settings、polls、votes、checkins、admin_sessions、admin_audit 表；保留原 notes、likes、photos 和 note_cooldowns。数据库启动时执行幂等建表，内置投票采用软删除，重新部署不会复活已删除投票。
- 本地未设置 ADMIN_PASSWORD_HASH 时后台保持关闭，不提供默认公开密码。只生成哈希可使用 `node --input-type=module -e "import {hashPassword} from './admin.js'; console.log(await hashPassword(process.env.NEW_ADMIN_PASSWORD))"`，通过环境变量提供待设置的新密码，避免把密码写进命令历史。

首页班级影像使用 public/assets/class-film.mp4，提供原生视频播放、手机内联和全屏控制、HTTP 字节范围请求。文件位于 Git 仓库并随部署发布，不占用相册数据库容量。

## 四个共享互动功能

- 默契挑战：五个固定趣味问题，每个浏览器一份，可重新作答。按当前所有参与者的主流选择计算吻合率，并列主流答案都算吻合；结果会随同学参与动态变化。显示前 20 名，最多 500 份作答，不是实名或考试评分。
- 时光胶囊：昵称 16 字、标题 60 字、正文 1000 字；开启时间按北京时间选择，服务器保存 UTC。只能选择 1 分钟后至 10 年内的时间。列表最多 200 个，每个浏览器最多 5 个。服务器查询使用 CASE 在到期前返回 null，作者及其他同学的接口不会提前收到正文，已登录管理员通过受保护的管理接口可提前查看全文；到期后全班可读。数据库维护者仍可直接访问数据库中的存储内容，本功能不提供端到端加密。
- 共享涂鸦墙：每个人在独立画布绘画后发布到共享作品墙。支持颜色、粗细、撤销、清空、鼠标及触摸。最多 150 笔、6000 个采样点，单笔最多 400 点；颜色及坐标由服务端验证。向量笔画保存到云端，作品在进入视野时按需读取并绘制，不接受 SVG 或任意 HTML。最多 100 幅，每浏览器最多 5 幅。
- 班级成就墙：管理员发布图标、标题、日期和说明，全班查看，最多 100 项。管理员可删除成就。
- 当前浏览器可删除自己的胶囊及涂鸦；管理员可删除全部胶囊、涂鸦、挑战记录及成就。新管理区域默认折叠，原留言/照片折叠功能保留。
- 新增 class_challenges、class_capsules、class_drawings、class_achievements 表，其他表和原有内容继续保留。使用现有数据库、登录机制及免费服务，不需要新增 API 密钥或付费资源。
- 数据同步沿用现有活跃页面每 30 秒同步、隐藏/空闲暂停机制。胶囊到期后刷新或下次同步可查看正文。查询参数或浏览器时间不会改变服务器解锁结果。

首页新增七位班级吉祥物展示：猪、甲鱼、鸡、野猫、猫头鹰、狗、熊猫。时光胶囊的公共接口继续屏蔽未到期正文，仅管理员鉴权后的后台接口允许提前查看；前台及后台说明同步更新。
